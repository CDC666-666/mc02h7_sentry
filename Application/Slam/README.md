# SLAM 定位模块（仅接收与显示）

本模块接收 `slam_mode_3d_v1.0` 的串口定位帧，并通过现有 UART10 网页遥测显示。
当前版本不参与底盘、云台、电机或 CAN 控制。

## 接线与串口参数

| SLAM 模块 | H723 控制板 |
| --- | --- |
| TX | UART7_RX / PE7 |
| GND | GND |
| RX（可选） | UART7_TX / PE8 |

- SLAM 模块供电为 5 V；必须和控制板共地。
- UART7 参数为 `115200, 8N1`。
- 接入前确认模块 TX 是 3.3 V TTL。若为 5 V TTL，必须先进行电平转换，不能直接接 PE7。

## 数据格式

固定 14 字节：

```text
AA | XH XL | YH YL | ZH ZL | RollH RollL | PitchH PitchL | YawH YawL | 0A
```

- X/Y/Z：有符号 16 位大端。随附旧版说明书标为 cm/14 字节帧，但当前模块实测输出为带校验的 15 字节帧，位置比例为 `0.1 mm/计数`；固件统一换算为米显示。
- Roll/Pitch/Yaw：有符号 16 位大端，实际模块输出单位为 `0.01 度`；固件已换算为度显示。
- 坐标系：前方 X 正、左方 Y 正、上方 Z 正。
- 首帧后的 200 ms 内未收到新帧，网页显示为离线。

## 验证

1. 烧录最新固件，打开 `Tools/ImuVisualizer/index.html`。
2. 用原来的 UART10 网页调试串口以 921600 打开网页。
3. 在网页顶部的 `SLAM 状态`、`SLAM X / Y`、`SLAM Yaw` 查看数据。
4. 静止后向车头前推，应优先确认 X 是否增加；若坐标轴不符合实际，先在厂家上位机配置模块安装方向，暂不在底盘控制中做补偿。

网页还会记录 `slam_frames`、`slam_errors`、`slam_age`；它们分别用于判断完整帧、协议错帧与最后一帧的新鲜度。
