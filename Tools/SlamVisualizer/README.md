# SLAM 高速调试网页

此工具只显示 `slam_mode_3d_v1.0` 的数据，不显示电机、CAN、遥控器或 IMU 调试项。

## 使用

1. 烧录包含 `slamdbg` 遥测的最新固件。
2. 双击 `start.bat`，浏览器打开 `http://localhost:8001/`。
3. 使用 Chrome 或 Edge，选择 UART10 的 921600 波特率串口并连接。

页面显示原始 X/Y/Z 计数、换算后的米数、相对连接时的变化量、姿态、数据年龄和协议错误数。

当前比例：X/Z 为 `0.0001 m/计数`，Y 为 `0.00001 m/计数`（Y 再缩小十倍）。
