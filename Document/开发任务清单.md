## 双 H7 控制板

建议的职责划分：

| 控制板 | 模块 |
| --- | --- |
| H7-A（底盘板） | 底盘电机、底盘运动学、功率限制、裁判系统、里程计/导航 |
| H7-B（云台板） | 云台电机、云台 IMU、发射机构、视觉/自瞄与遥控器输入 |

### 板间通信决策

第一阶段采用一条独立的经典 CAN 总线，不与任何 DJI、DM 或 EVO 电机共线：

- 预留两块板的 CAN3，仅用于 `BoardLink` 板间协议。
- 波特率为 `1 Mbps`；两板的 CANH 对 CANH、CANL 对 CANL、GND 对 GND，总线物理两端各一个 `120 Ohm` 终端电阻。
- 控制量、状态量和裁判摘要全部使用定长 8 字节经典 CAN 帧；不转发裁判串口的原始字节流。
- 后续只有在需要传输 SLAM 大数据、自瞄目标列表或大量调试数据时，才升级到 CAN FD。升级前必须确认两端收发器均支持 CAN FD，并统一仲裁速率、数据速率与 BRS 配置。

经典 CAN 的传输和响应已经足以满足双板闭环控制：姿态/底盘命令可达 200 Hz 以上，单帧总线传输通常约 0.1 至 0.2 ms。FDCAN 提高的是大数据帧吞吐，并不会自动改善当前控制逻辑。

### 第一版报文规划

| CAN ID | 方向 | 内容 | 建议频率 |
| --- | --- | --- | --- |
| `0x301` | 云台板 -> 底盘板 | 云台 Yaw 角、Yaw 角速度、云台模式、在线状态 | 200 Hz |
| `0x302` | 云台板 -> 底盘板 | `vx`、`vy`、`wz`、底盘模式、使能状态 | 100 至 200 Hz |
| `0x303` | 底盘板 -> 云台板 | 底盘实际速度、功率限制、底盘在线状态 | 50 至 100 Hz |
| `0x304` | 双向 | 协议版本、心跳序号、遥控器状态、急停与故障位 | 50 至 100 Hz |
| `0x310` | 底盘板 -> 云台板 | 裁判机器人状态：ID、HP、比赛阶段、裁判在线 | 10 至 20 Hz |
| `0x311` | 底盘板 -> 云台板 | 发射限制：热量、热量上限、冷却、射速、允许发射 | 20 至 50 Hz |
| `0x312` | 底盘板 -> 云台板 | 功率限制：功率上限、缓冲、实际功率 | 20 至 50 Hz |

具体字节布局、缩放倍率、大小端、有效位和协议版本号必须在实现前另建协议文档固定；跨板数据优先使用缩放后的整数，不直接传输 `float`。

### 控制权与安全要求

- 云台板解析遥控器并向底盘板发送底盘目标；底盘板只执行目标并负责本地底盘安全保护。
- 云台板发送 Yaw 状态；底盘板据此将操作者的平移命令由云台坐标系转换到车体坐标系。
- 裁判串口只接底盘板。底盘功率限制始终在底盘板本地执行；云台板收到裁判摘要后负责发射策略和状态显示。
- 每个关键报文包含递增心跳/序号。任一板连续 `50 ms` 未收到对方有效心跳，必须清零所有跨板运动命令，并进入本板安全状态。
- 遥控器掉线、急停、对方掉线或本板关键电机离线时，禁止保留上一次跨板控制指令。
- 两块板必须具有独立 profile 和角色定义，禁止向同一电机同时发送控制帧。

建议实施顺序：先完成底盘单板测试，再完成云台单板测试；随后加入板间心跳与掉线失能，最后再联调整车遥控器、功率和网页监测。

## 通用安全要求

- 新电机第一次接入时只接单台，架空并限幅测试。
- 修改 CAN、ID、方向、零位、PID 或功率参数后，先验证反馈再验证运动。
- 不明确机械行程时，不开启位置闭环和自动使能。
- 板间、视觉或遥控器掉线必须输出安全命令，不允许保留最后一次运动指令。
